Services P&L

A services P&L by line of business: actual vs budget, forecast or prior year for MTD, QTD, YTD and full year, as scorecards, a grid, a matrix or a monthly trend.

Download .pbiviz All downloads and install steps

Need help? Open an issue. Include the version from Format pane › About.

Requirements

  • Power BI Desktop (current release), the Power BI service or Power BI Report Server with custom visuals enabled.
  • A date or month column, and at least one actual measure.

Setting up

Field wellWhat to add
CategoryOptional. Line of business, stream or practice, one or two levels. Use the field your budget is planned on.
SlicerOptional. A field shown as buttons above the view (for example Stream). It filters this visual only.
MonthRequired. A date at month level or finer, ideally from a marked date table.
Actual linesRequired. One measure per P&L line, revenue first (Revenue, COGS, Payroll…). A measure named GM, Gross Margin or Margin is used as the margin line.
Budget linesOptional. Budget measures, matched to the actual lines by name (Revenue ↔ Revenue Bud), in any order.
Forecast linesOptional. Forecast measures, matched by name. They also fill the remaining months of the full year.
Info linesOptional. Measures shown with actuals only and left out of the margin (milestones, pipeline, headcount).

Costs can be stored as negative (default) or positive values: set this in Format pane › P&L lines.

Troubleshooting

The vs PY button is missing or prior year is empty

Prior year is the actual for the same months one year earlier, so the visual needs last year’s months. A page or report date slicer that keeps only the current year removes them. Set that slicer’s interaction with this visual to None (Format › Edit interactions) and use the visual’s own as-of month picker.

The vs FC button is missing

It appears once at least one Forecast measure is bound and returns data.

Margin looks doubled

Name your margin measure GM, Gross Margin or Margin so the visual uses it as the margin line instead of adding it as a cost, or leave it out and let the visual calculate margin from the lines.

Budget is paired with the wrong line

Budget and forecast measures are matched to actual lines by name. Give them names that share the line name (Revenue / Revenue Bud / Revenue FC; COGS / COGS Bud).

A category shows “BU only” or “no AC”

That category has budget but no actuals in the selected period. This usually means budget and actuals are planned on different fields; put the field the budget uses in Category.

Removing a cross-filter

Click the selected item again, click empty space, press Esc or use ✕ Clear selection in the header.

Drill through does not appear

Right-click a category. Power BI shows Drill through when a drillthrough page uses the same field as the visual’s Category.

Keyboard use

Tab moves to categories, Enter or Space selects (Ctrl adds), Shift+F10 opens the context menu and Esc clears the selection.

Known limitations

  • Other visuals filter this one rather than highlighting it, so every figure, variance and margin % is recalculated for the selection.
  • The interface is in English.
  • Up to 30,000 category × month rows are loaded.

Privacy

The visual has no network access and does not collect, send or store your data. See the privacy policy.
