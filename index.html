Before you report a problem

  • Update Power BI Desktop to the latest monthly release.
  • Check the visual version in the Format pane (About card), and update the visual from AppSource if a newer one exists.
  • Remove and re-add the fields, then check whether the problem still happens on a new, empty report page.
  • Please do not send confidential data. A screenshot with the numbers blurred, or a small sample .pbix with made-up data, is enough.
