Team Activity Timeline

When each person was available, on call or away (and why), with tickets and calls, per day, week, month or year. Works with ServiceNow data.

Download .pbiviz All downloads and install steps

Need help? Open an issue. Include the version of the visual, your Power BI Desktop version and a screenshot.

Requirements

  • Power BI Desktop (current release), the Power BI service or Power BI Report Server with custom visuals enabled.
  • A person field and a start date/time; status and / or event rows.

Setting up

Field wellWhat to add
PersonRequired. One row per person.
Start (date/time)Required. When the status or event began. Use the Date/Time column itself, not the date hierarchy.
End (date/time)Optional. Without it a status lasts until the person’s next status.
StatusRequired for status rows. Any values work; new ones get a color automatically.
Status groupOptional. Groups statuses for colors and totals.
Reason / detailOptional. Why the person was away, or a short description of a ticket or call.
Event typeRequired for event rows (Ticket, Call, Chat…).
Event IDOptional. Ticket or call number, shown in the tooltip.
TeamOptional. Collapsible team headers with totals.
Extra tooltip fieldsOptional. For text fields choose First or Last as aggregation.

Troubleshooting

People should not be identifiable

Use Hide names or Show rows for: Teams only, and check your company’s policy before sharing a report that shows individuals’ time.

Total columns disappear

Columns that do not fit next to a usable chart are dropped from the right. Widen the visual or list fewer columns under Total columns.

Only part of the data is shown

Turn on Load more than 30,000 rows under Data loading (default limit 300,000 rows).

A status is cut short

Status rows are a sequence per person, so a status that overlaps the next one ends where the next one starts.

Removing a cross-filter

Click the selected item again, click empty space or press Esc.

Keyboard use

Tab to a name, Up / Down move between rows, Enter selects a person or expands a team, Left / Right collapse or expand a team (outside the rows they move to the previous or next period), Shift+F10 opens the context menu and Esc clears.

Known limitations

  • Highlighting from other visuals needs a measure in Extra tooltip fields; without one, other visuals filter this visual instead.
  • The interface is in English.

Privacy

The visual has no network access and does not collect, send or store your data. See the privacy policy.
