Org Hierarchy Chart

A top-down organization chart with search, branch focus, span-of-control flags, metrics and cross-filtering.

Download .pbiviz All downloads and install steps

Need help? Open an issue. Include the version of the visual, your Power BI Desktop version and a screenshot.

Requirements

  • Power BI Desktop (current release), the Power BI service or Power BI Report Server with custom visuals enabled.
  • An employee ID and a manager ID column (the manager's employee ID; blank for the top).

Setting up

Field wellWhat to add
Employee IDRequired. Unique ID of each person.
Manager IDRequired. Employee ID of the manager; blank for the top. People whose manager is not in the data become top level.
Employee nameOptional. Card text, also searched.
Job titleOptional. Card subtitle, also searched.
Color byOptional. Colors the card strip and avatar, with a legend.
Photo URLOptional. Profile picture; initials are shown otherwise. See the note on photos below.
Metric (card value)Optional. Shown as a bar on each card; also used for the heatmap and roll-up.
Extra tooltip fieldsOptional. Additional fields in the tooltip.

Troubleshooting

Some people appear at the top level

Their Manager ID does not match any Employee ID in the filtered data. Check for filters that remove managers, and for IDs stored with different types or spaces.

Photos do not show

The browser loads pictures directly from the URL, so the viewer must be able to open that address (signed in, same network). Depending on your Power BI version and settings, Power BI may block pictures from external addresses; initials are shown instead.

The chart is slow for a large organization

Only expanded levels are drawn. Start with L1 to L3 and use search or Team focus.

Expanded branches reset

The expand / collapse state is not saved with the report.

Note on photos

When the Photo URL well is used, the viewer’s browser requests each picture from the address in your data. No report data is sent with these requests and we never receive them; see the privacy policy. Leave the well empty or turn Show photos off to avoid them.

Keyboard use

The chart is one tab stop: arrow keys move through the tree, Right / Left expand or collapse, Home / End jump, Enter or Space selects, Shift+F10 opens the context menu and Esc clears.

Known limitations

  • Up to 30,000 people are loaded.
  • Expand / collapse state is not remembered between sessions.
  • Other visuals filter this one rather than highlighting it.
  • The interface is in English.

Privacy

The visual does not collect, send or store your data; the only requests it causes are the photo downloads described above. See the privacy policy.
