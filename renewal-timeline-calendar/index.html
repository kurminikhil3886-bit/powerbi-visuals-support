Renewal Timeline Calendar

A swimlane timeline for opportunities, contracts and renewals with notice windows, renewal alerts, milestones, dependencies and zoom levels.

Download .pbiviz All downloads and install steps

Need help? Open an issue. Include the version of the visual, your Power BI Desktop version and a screenshot.

Requirements

  • Power BI Desktop (current release), the Power BI service or Power BI Report Server with custom visuals enabled.
  • A title field and at least one of start date or end / renewal date.

Setting up

Field wellWhat to add
TitleRequired. Row label and bar text.
Item IDOptional. Unique ID, referenced by Depends on.
Swimlane / GroupOptional. One collapsible lane per value.
Start dateOptional. Bar start; leave empty for a single-date milestone. Use the date field itself, not the date hierarchy.
End / Renewal dateRequired if there is no start date. Bar end and renewal diamond.
Notice / cancel-by dateOptional. Hatched notice window before the renewal.
Status / CategoryOptional. Colors bars; closed statuses are muted and never alert.
Depends onOptional. Predecessor IDs, separated by , or ;
ValueOptional. Amount shown next to bars, in lane headers and summary cards.
Progress %Optional. 0–1 or 0–100, fills the bar.
Notice period (days)Optional. Alternative to a notice date.
Extra tooltip fieldsOptional. For text fields choose First or Last as aggregation.

Troubleshooting

Items disappear when I add a measure

Power BI drops rows where every measure is blank. Give such items a value (for example 0) or turn on Show items with no data for the Title field.

Dates show as Year / Quarter / Month

Use the date column itself instead of the automatic date hierarchy.

Alerts are based on the wrong date

Alerts use the notice date by default; switch to the renewal date and change the 30 / 60 / 90-day thresholds in the Format pane.

A dependency arrow is red and dashed

The successor starts before its predecessor ends. Hover the item to see the conflict.

Removing a cross-filter

Click the selected item again, click empty space or press Esc.

Keyboard use

Tab into the rows, then arrow keys move, Left / Right collapse or expand a swimlane, Home / End jump, Enter selects, Shift+F10 opens the context menu and Esc clears.

Known limitations

  • Up to 30,000 rows are loaded.
  • The interface is in English.

Privacy

The visual has no network access and does not collect, send or store your data. See the privacy policy.
