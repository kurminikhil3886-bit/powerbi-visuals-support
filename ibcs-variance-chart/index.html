IBCS Variance Chart

An IBCS-style variance chart for periods: actual columns against plan, previous year or forecast, with absolute and relative variances, a total column, callouts, a generated headline and a table view.

Need help? Open an issue. Include the version of the visual, your Power BI Desktop version and a screenshot.

Requirements

  • Power BI Desktop (current release), the Power BI service or Power BI Report Server with custom visuals enabled.
  • A category field for the periods (usually months), sorted chronologically, and an actual measure.

Setting up

Field wellWhat to add
Category (period / item)Required. Items on the horizontal axis, usually months. Use the date field itself, not the date hierarchy.
Actual (AC)Required. Leave it blank for future periods.
Plan / Budget (PL)Optional. Outlined comparison column; basis of ΔPL and ΔPL%.
Previous year (PY)Optional. Grey comparison column; basis of ΔPY and ΔPY%.
Forecast (FC)Optional. Hatched column for periods without an actual.
Callout textOptional. A comment per period, shown as a numbered circle and a list.
Extra tooltip valuesOptional. Additional measures in the tooltip.

Troubleshooting

Increases in costs show green

Turn off Higher is better (Format pane › Chart) for costs, terminations and similar measures.

Months are in the wrong order

Sort the month column by a month number, or use a date field instead of the date hierarchy.

The total looks wrong for a ratio or balance

Set Total aggregation to Average or Last value.

Some value labels are missing

Labels are drawn only when they fit their column. Widen the visual, reduce the text size or hover a column for every value.

A comparison button is missing

vs PY, vs PL and vs FC appear only for the comparisons that have a field.

Removing a cross-filter

Click the selected item again, click empty space or press Esc.

Keyboard use

Tab moves to the columns (or table rows), arrow keys move between them, Enter or Space selects (Ctrl adds), Shift+F10 opens the context menu and Esc clears the selection.

Known limitations

  • Up to 30,000 periods are loaded.
  • While another visual highlights, the highlighted part of each column is solid; Δ, Δ% and the headline stay on the full values.
  • The interface is in English.

Privacy

The visual has no network access and does not collect, send or store your data. See the privacy policy.
